# Mega Dental Plus · Prótesis Dental

Sitio web one-page (HTML + CSS + JS, sin dependencias) para **Mega Dental Plus CA / Megadental – Prótesis Dental**, Hans Christian López Guerrero. Mérida, Venezuela.

## Estructura
- `index.html` – página principal
- `css/styles.css` – estilos
- `js/main.js` – menú, animaciones, FAQ y formulario a WhatsApp
- `assets/logo-mark.svg` – logotipo

## Uso
Abrir `index.html` en el navegador, o publicar con GitHub Pages (Settings → Pages → rama `main`).
